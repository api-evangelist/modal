# Modal GraphQL API

Modal is a serverless cloud platform for AI and data science workloads. The API covers function deployment, GPU compute allocation, job scheduling, volume management, secrets, web endpoints, and async task execution.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Modal REST/gRPC API
**Documentation:** https://modal.com/docs

- Reference: https://modal.com/docs/reference
